# TechComponentes - PC Hardware Store

A Vue 3 + Vite e-commerce frontend for a PC Hardware Store.

## Tech Stack

- **Framework**: Vue 3 (Composition API)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS (Dark "Gamer" Theme)
- **State Management**: Pinia
- **Router**: Vue Router
- **Icons**: Lucide Vue Next

## Features

- **Home Page**: Featured products and hero section.
- **Catalog**: Product listing with category filtering.
- **Shopping Cart**: Add/remove items, update quantities, real-time total calculation.
- **Responsive Design**: Mobile-friendly navbar and layout.

## Project Setup

### Install Dependencies

```sh
npm install
```

### Run Development Server

```sh
npm run dev
```

### Build for Production

```sh
npm run build
```
